# page, artists, projets

Pour ajouter un document, dans la liste des projets cliquer sur le bouton +. Depuis le header cliquer sur le bouton + (à côté du chanmps rechercher)

Pour supprimer un document, dans la page d'édition du document, en bas à droite dans les ... à côté du bouton publier cliquer sur le bouton supprimer.

Pour dépublier un document, dans la page d'édition du document, en bas à droite dans les ... à côté du bouton publier cliquer sur le bouton Unpublish.

Pour dupliquer un document, dans la page d'édition du document, en bas à droite dans les ... à côté du bouton publier cliquer sur le bouton dupliquer.

# pages

Toutes les pages sont disponibles dans la section "Pages". Chacun peux devenir la home page, suffit de clique sur le switch.
Titre, slug (click sur generate), modules.

Les modules sont pré remplis avec du contenu sample. À vous de l'éditer.

renseigner:

- title
- slug (url) (cliquer sur generate)
- Module Home Feed
- - renseigner l'artiste
- - renseigner le projet
- - renseigner les media 1 ou 2 max. Image ou video
- Module Artists Grid
- - liste les artistes en fonction du tag
- Module Productions
- - renseigner le text,
- - le featured production (image, titte, sous titre)
- - les productions (image, titte, sous titre)
- - le texte en pids de pages

À savoir il est possible de combiner les modules et créer un page qui scroll et enchaines ces modules.
